# Grafana

Provisioned at startup, so `make up` gives a working dashboard with no clicking:

- `provisioning/datasources/prometheus.yml`: Prometheus at `http://prometheus:9090` (uid `prometheus`)
- `provisioning/dashboards/dashboards.yml`: loads every JSON file in `dashboards/`
- `dashboards/codesearch.json`: the CodeSearch dashboard, generated by `make_dashboard.py`

Open http://localhost:3000 (admin / the `GRAFANA_ADMIN_PASSWORD` from `.env`).

To change the dashboard, edit `make_dashboard.py` and run
`uv run python deploy/grafana/make_dashboard.py`, or edit in the Grafana UI and
export the JSON back over `dashboards/codesearch.json`.
